# Agent instructions

This repository contains personal engineering policy, not an application.

1. Read README.md and docs/architecture.md.
2. Read only the standards relevant to the task.
3. Before changing a rule, read docs/contributing.md and docs/versioning.md.
4. Run the checks in docs/testing.md before handing off changes.
5. Before publishing or updating a PR, run pre-commit against all files using the command in docs/testing.md, fix failures, and report the result.

Keep organization-specific workflows, issue trackers, runtime assumptions, and product names out of shared policy. Put adoption instructions in docs/ and copyable consumer guidance in templates/. Do not duplicate shared policy in templates.

Preserve source attribution and license notices. Do not claim a release or remote repository exists before verifying it. Do not publish a release, merge, or deploy without authorization.
