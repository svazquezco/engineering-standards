# Engineering standards

Personal engineering standards for applications, tools, and libraries. These documents are shared references for people and AI agents; each consuming repository owns its commands, architecture, and documented exceptions.

## Standards

| Standard | Applies to |
| --- | --- |
| [Documentation](standards/documentation.md) | All repositories |
| [Branching](standards/branching.md) | Git workflows |
| [Commit messages](standards/commit-messages.md) | Git commits |
| [Pull requests](standards/pull-requests.md) | Reviewed changes |
| [Testing](standards/testing.md) | Executable projects |
| [Python coding](standards/python-coding.md) | Python source code |
| [Python unit tests](standards/python-testing.md) | Python unit tests |
| [Dependencies](standards/dependencies.md) | Python dependency management |
| [Makefiles](standards/makefiles.md) | Projects using Make |

## Adopt

Follow [adoption](docs/adoption.md) to pin a revision and add references to your project. Start with [the agent template](templates/AGENTS.md), replacing its placeholders. Shared standards are not automatically loaded or enforced by linking them: an agent must read the relevant documents, and tooling must be configured separately.
