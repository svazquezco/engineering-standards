# Documentation

Scope: all repositories.

- Keep README.md as the human entry point: purpose, quick start, and links to detailed docs.
- Keep AGENTS.md as the agent entry point: reading order, relevant policy references, commands, and exceptions.
- Provide docs/architecture.md for components and boundaries, docs/contributing.md for local development workflow, and docs/testing.md for test strategy and exact commands.
- Add deployment, migrations, integrations, and local-development documents when applicable.
- Link to shared standards at a pinned revision. Document local behavior and exceptions without duplicating shared policy.
- Keep tool-specific instruction files thin, pointing to AGENTS.md.
- Use focused documents, predictable names, and short valid examples. State requirements with must, should, or may.
- Update affected documentation in the same change as behavior. Do not describe planned features as available.
